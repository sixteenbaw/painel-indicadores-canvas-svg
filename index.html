Painel de Indicadores Web

Comparação entre gráficos Canvas e SVG

Apresentação

Este projeto apresenta os indicadores de domínio de quatro tecnologias utilizadas no desenvolvimento front-end: HTML, CSS, JavaScript e SVG.

Os mesmos dados foram representados em dois gráficos de barras, utilizando Canvas e SVG, para comparar suas características e formas de implementação.
